# F-17 | Micronutrient Tracking

## Overview
Track vitamins, minerals, sodium, cholesterol, and other extended nutrient metrics.

## User story
As a more advanced user, I want deeper nutrition insights so I can monitor more than calorie and macro totals.

## Acceptance criteria
- The app can store extended nutrient values for a logged meal.
- The dashboard exposes detailed nutrient breakdowns when available.

## MVP status
Necessary for MVP: No
