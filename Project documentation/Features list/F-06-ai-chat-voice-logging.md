# F-06 | AI Chat / Voice Logging

## Overview
Support voice input for quick meal logging through conversational commands.

## User story
As a user, I want to speak my meal instead of typing so logging feels faster and more natural.

## Acceptance criteria
- The app supports voice input for quick meal creation.
- The transcription is converted into an AI suggestion.
- The user can confirm or edit the result.

## MVP status
Necessary for MVP: No
