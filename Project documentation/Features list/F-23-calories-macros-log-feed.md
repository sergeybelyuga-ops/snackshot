# F-23 | Calories & Macros Log Feed

## Overview
Provide a dedicated place where the user can review the detailed history of all tracked meals in reverse chronological order. Each entry includes the time it was logged, the food name, a photo if one was captured, and the calories and macros for that item.

## User story
As a user, I want a clear meal history so I can review what I ate, check the exact values for each entry, and make quick corrections when needed.

## Main functionality
- The user can see a detailed log of all tracked meals in historical order.
- Each log entry includes:
  - date and time,
  - product or meal name,
  - photo if captured,
  - calories,
  - macros.
- The user can edit an existing log entry if the value needs correction.
- The user can delete a log entry from the history.

## Acceptance criteria
- The app displays a chronological list of all meal entries.
- Each item shows the logged date and time.
- Each item shows the product or meal name.
- Each item includes the photo if the meal was added from a camera or gallery image.
- Each item shows calories and macro values.
- The user can open a log entry to adjust its values.
- The user can remove a log entry permanently.
