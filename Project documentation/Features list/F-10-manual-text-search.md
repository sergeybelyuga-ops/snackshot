# F-10 | Manual Text Search

## Overview
Provide a fallback where the user can search for a food item manually if AI recognition is uncertain or incorrect.

## User story
As a user, I want a quick text search fallback so I can still log my meal when recognition does not match the food I ate.

## Acceptance criteria
- The user can search a food database by name.
- Search results include common matching items and nutrition values.
- The user can select a result and save it to the log.
- The flow is faster than full manual entry.

## MVP status
Necessary for MVP: Yes (Basic)
