# F-16 | Macronutrient Dashboard

## Overview
Show the user how much protein, fat, and carbohydrates they have consumed across today, previous days, and the full weekly period. The weekly board includes all seven days of the week and the daily average for each macro category.

## User story
As a user, I want to see my macro breakdown for today, past days, and the full week so I can understand my meal quality over time and compare my daily pattern to the weekly average.

## Main functionality
- The user can see consumed calories and macros for today.
- The user can review consumed calories and macros for previous days.
- The user can switch to a weekly view that shows nutrition for all 7 days of the selected week.
- The weekly view also includes the average value per day for calories, protein, carbohydrates, and fat.
- The dashboard is readable and visually organized for quick comparison across days.

## Acceptance criteria
- The app displays calories, protein, carbohydrates, and fat totals for the current day.
- The user can browse historical daily totals for earlier dates.
- The app provides a weekly summary for the selected week.
- The weekly summary includes all 7 days of the week with their own totals for each macro category.
- The weekly summary also shows the average daily values for each macro category.
- The values are derived from logged meals and updated automatically as new entries are saved.
