# F-13 | Custom Recipes / Meals

## Overview
Allow the user to save reusable meal combinations and ingredients as a single recipe template.

## User story
As a user, I want to save a recurring meal so I can log it faster in the future.

## Acceptance criteria
- The user can create a custom recipe with ingredients and portion values.
- The app can save and recall the recipe later.
- The saved recipe can be logged with one action.

## MVP status
Necessary for MVP: No
