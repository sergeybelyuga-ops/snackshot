# F-07 | Best Photo Practices

## Overview
Guide the user to take a better photo before scanning by showing short, practical instructions.

## User story
As a user, I want simple guidance on how to frame my food so the AI can recognize it more accurately.

## Acceptance criteria
- The user sees brief guidance before or during capture.
- The instructions are simple and visually clear.
- The guidance helps improve recognition quality without adding friction.

## MVP status
Necessary for MVP: No
