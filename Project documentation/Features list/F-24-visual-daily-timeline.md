# F-24 | Visual Daily Timeline

## Overview
Present the day's meals in a time-based timeline separated by meal category.

## User story
As a user, I want a daily timeline so I can quickly see what I have eaten across the day.

## Acceptance criteria
- Meals are grouped by time or meal type.
- The UI is easy to scan.
- The user can inspect previous entries without extra navigation.

## MVP status
Necessary for MVP: No
