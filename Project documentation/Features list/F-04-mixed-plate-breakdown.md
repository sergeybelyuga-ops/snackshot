# F-04 | Mixed Plate Breakdown

## Overview
Identify multiple food items on the same plate or in one dish and assign separate portions to each one.

## User story
As a user, I want the app to break down a mixed meal accurately so I can log complex dishes without manual entry.

## MVP status
Necessary for MVP: No

## Future use
This is a post-MVP enhancement intended for meals with layered or mixed ingredients.
