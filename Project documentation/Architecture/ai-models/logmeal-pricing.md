# LogMeal API Pricing

The LogMeal API provides food detection, recognition, and tracking capabilities.

## Plans

The pricing page presents standard plans with monthly subscriptions. The visible basic example prices are:

| Plan | Monthly price |
| --- | ---: |
| Basic example | 144 EUR/month, excluding VAT |
| Standard example | 316 EUR/month, excluding VAT |
| Advanced example | 488 EUR/month, excluding VAT |
| Custom | Contact LogMeal |

Standard plans allow up to 20 images per day per end user (`APIUser`) and 1 image per second per end user. Alternative requirements require a Custom plan.

The pricing page states that LogMeal operates on a credit-based system. Each API request consumes either one credit or no credits depending on the endpoint. Each plan includes a number of monthly credits; calls beyond the allocation are charged additionally.

All customer support is email-based, with the technical team answering within 24-48 hours Monday through Friday. The Custom plan offers more direct developer contact for personalized support.

## Trial

New members can try the full API for 30 days, with a maximum of 200 queries and 5 registered users.

For current details, refer to the [full API documentation](https://docs.logmeal.com/) and the [LogMeal pricing page](https://logmeal.com/api/pricing/).
