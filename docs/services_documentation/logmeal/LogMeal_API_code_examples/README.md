# LogMeal API - Code Examples

Welcome! This package contains ready-to-use code examples to help you quickly integrate the LogMeal API ([https://logmeal.com](https://logmeal.com)) into your application. 

These scripts are designed to demonstrate how to perform basic API calls, handle authentication, and process responses in multiple programming languages.

## Prerequisites

1. **API Token:** You need a valid LogMeal API Token. If you don't have one, sign up at [LogMeal](https://logmeal.com) to get yours.
2. **Test Image:** We have included a sample image (`multiple_items_meal.jpg`) in this directory for testing purposes. If you want to use your own image, simply update the file path in the code.
3. **Environment:** Ensure you have the appropriate runtime or compiler installed for the language you wish to test.

## Setup Instructions

Before running any script, open the specific file in your code editor and look for the authentication variable (e.g., `API_TOKEN = "YOUR_TOKEN_HERE"`). 
Replace the placeholder with your actual API User Token (or Company Token, depending on the endpoint permissions).

## How to Run the Examples

Open your terminal, navigate to the root folder of this unzipped package, and run the command for your preferred language:

### Python
```commandline
python3 file-name.py
```

### JavaScript
```commandline
node javascript/file-name.js
```

### TypeScript
```commandline
npx ts-node typescript/file-name.ts
```

### PHP
```commandline
php php/file-name.php
```

### Dart
```commandline
dart dart/file-name.dart
```

### Swift
```commandline
swiftc swift/file-name.swift -o recipe && ./recipe
```

### Java
```commandline
java -cp "java/lib/*:." java/file-name.java
```

### C#
```commandline
dotnet run --project csharp/
```

### Kotlin
```commandline
java -cp "kotlin/recipe.jar:lib/ *" file-nameKt "
```
