# F-15 | Calorie Tracking

## Overview
Compare consumed calories against a daily target and help the user monitor total intake.

## User story
As a user, I want to see my daily calorie intake so I can keep track of my nutrition goals.

## Acceptance criteria
- The app sums calories from saved meals.
- The daily total is displayed in a clear dashboard.
- The target is taken from the Health Connect or configured user goal.
- The user can review calories across the day.

## MVP status
Necessary for MVP: No
