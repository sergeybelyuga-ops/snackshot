## Overview
Offer a one-tap shortcut to repeat a previously logged meal.

## User story
As a user, I want to repeat a meal I ate before so I can log it quickly without re-entering the details.

## Acceptance criteria
- The app shows previous meals in a quick list.
- The user can duplicate a previous entry with one tap.
- The duplicate can be adjusted before saving.

## MVP status
Necessary for MVP: No
