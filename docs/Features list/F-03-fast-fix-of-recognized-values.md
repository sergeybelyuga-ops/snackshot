# F-03 | Fast Fix of Recognized Values

## Overview
Let the user quickly revise the AI's guess for the detected food item, weight, or calories without breaking the logging flow.

## User story
As a user, I want to fix the AI guess quickly when it is close but not exact so I can finish logging in seconds.

## Acceptance criteria
- The user can edit food name, portion, or weight from the result screen.
- Corrections are reflected instantly in the calorie/macro totals.
- The edit flow is a small, lightweight interaction rather than a full re-entry flow.
- The corrected values are saved with the log entry.

## MVP status
Necessary for MVP: Yes
