# F-25 | Statistic Dashboard

## Overview
Show trends over time, including consumption patterns and historical macro values.

## User story
As a user, I want to see my trends over weeks and months so I can understand whether my habits are improving.

## Acceptance criteria
- The app displays charts or summaries for historical nutrition data.
- The charts are easy to interpret.
- The user can review trends without deep analysis.

## MVP status
Necessary for MVP: No

The D / W / M / 3M / Y range views are delivered in the MVP as part of F-16. F-25 covers trend analysis beyond them.
