# F-27 | Water Tracker

## Overview
Allow the user to track hydration levels in a lightweight, quick-tap format.

## User story
As a user, I want to track my water intake so I can support my health goals alongside food logging.

## Acceptance criteria
- The user can log water intake in a quick format.
- The app stores the hydration record for the day.

## MVP status
Necessary for MVP: No
