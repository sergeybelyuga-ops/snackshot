# F-21 | Auto-Import Burned Calories

## Overview
Import workout-derived burned calories from other fitness applications to improve daily energy balancing.

## User story
As a user, I want my activity data to influence my calorie understanding so my nutrition data is more complete.

## Acceptance criteria
- The app can read relevant workout or expenditure data from supported health sources.
- The user can review imported values before they affect the daily summary.

## MVP status
Necessary for MVP: No
