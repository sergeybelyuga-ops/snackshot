# F-09 | Phone Gallery Usage

## Overview
Allow the user to choose an existing image from their phone gallery instead of taking a new photo.

## User story
As a user, I want to log a meal from a previously taken photo when I do not want to retake a picture.

## Acceptance criteria
- The user can open the gallery from the logging flow.
- The selected image is processed by the same AI recognition pipeline.
- The result can be reviewed and saved.

## MVP status
Necessary for MVP: Yes (gallery on S-02 Home and on the camera screen)
