# F-31 | User Profile Show & Configure

## Overview
Display and manage the user's profile and preferences in a dedicated settings area.

## User story
As a user, I want to review and update my profile information so the app matches my preferences and goals.

## Acceptance criteria
- The user can view their profile information.
- The user can update settings where relevant.
- The profile area is clearly separated from the meal logging flow.

## MVP status
Necessary for MVP: No
