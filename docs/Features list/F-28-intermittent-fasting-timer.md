# F-28 | Intermittent Fasting Timer

## Overview
Track fasting windows and eating schedules to support intermittent fasting routines.

## User story
As a user, I want to track fasting windows so I can stay aligned with my eating schedule.

## Acceptance criteria
- The app can start and end fasting intervals.
- The user can review elapsed time and schedule history.

## MVP status
Necessary for MVP: No
