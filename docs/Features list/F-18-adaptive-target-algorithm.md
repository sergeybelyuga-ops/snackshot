# F-18 | Adaptive Target Algorithm

## Overview
Automatically adjust daily calorie goals based on changes in user data and trend patterns.

## User story
As a user, I want my calorie target to adapt over time so it remains aligned with my goals.

## Acceptance criteria
- The app can incorporate weight or activity trend data when available.
- Goal adjustments are transparent and user-reviewable.
- The algorithm is optional and not required for core logging.

## MVP status
Necessary for MVP: No
