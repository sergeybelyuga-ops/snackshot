# Developer tools

- `fake-logmeal/` — local fake LogMeal server (port 8090) serving `test-fixtures/logmeal`.
- `logmeal-contract-check/` — manual check of fixtures against the real API with the test token.
- `adb-reverse.ps1` — forwards emulator ports to a USB phone or AVD.

See [12](../docs/Architecture/12_dev-and-test-environment.md) §3, §10.
